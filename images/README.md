## Image Guidelines

- **Quality**: High resolution, professional quality
- **Optimization**: Compress images for web (aim for under 500KB each)
- **Rounded corners**: Will be applied via CSS (border-radius: 1.5rem)
- **Responsive**: Images will scale automatically for different screen sizes
