Mon travail oscille entre les applications avec lesquelles les gens interagissent et les outils de recherche qui aident à étudier une question. Releaf met la durabilité dans une routine quotidienne. Mes recherches sur Phoenix demandent ce qu'une carte thermique laisse de côté. Le planificateur d’analyse étudie la manière dont une expérience pourrait utiliser ses mesures avec plus de soin.

Je m'intéresse aux décisions qui relient ces couches : comment les données sont organisées, ce qu'une interface rend compréhensible et comment savoir si un résultat soutient l'affirmation formulée.
