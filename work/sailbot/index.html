THE QUESTION

An autonomous boat has to turn imperfect information into a physical decision. My contributions to Kehillah Sailbot focused on navigation, steering, wind filtering, state estimation, and the simulator used to study the boat’s behavior.

01

Closing the loop

A navigation decision is only useful if the boat can follow it. I contributed to the software that connects estimated conditions with steering behavior, including filtering wind information and improving the state estimates used by the controller.

02

Respecting physical constraints

My work included model-predictive steering with constraints on rudder movement. Explicit movement limits let the controller reason about actions the mechanism can perform, rather than assuming it can instantly reach any desired position.

03

Learning in simulation

I also contributed to the physics simulator and control improvements for evaluating boat behavior. Simulation provides a way to examine how changes in navigation and steering affect the system before drawing conclusions about performance on the water.

INSIDE THE ENGINEERING

A decision becomes a rudder angle.

  1. 01

    Connect the control loop

    The team’s ROS 2 architecture separates sensor input, navigation, and actuation. GPS fixes and wind direction feed the control system, while rudder and sail commands travel on dedicated topics. That separation makes the data entering a decision and the command leaving it inspectable.

  2. 02

    Constrain the next move

    My model-predictive steering work included limits on rudder movement. A controller must choose from actions the mechanism can perform over time. State estimation and wind filtering improve the information used to make those choices under changing conditions.

  3. 03

    Study behavior before deployment

    The physics simulator provides a setting for examining navigation and control changes together. It connects the software question—what command should be issued?—with the physical question of how the boat responds. On-water performance remains a separate evaluation.

The repository documents the team’s ROS 2 system. My contributions focus on navigation, steering, wind filtering, state estimation, and simulation.
