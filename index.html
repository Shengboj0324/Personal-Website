CollegeAdvisor

04/ 08Teams2025–2026

Finding a heading

A boat cannot argue with the wind. This team’s autonomous sailboat reads a wind vane, a GPS and an inertial sensor, and has to turn those readings into a rudder angle it can physically reach.

05/ 08Research2025–present

Language in motion

Signing uses the hands, face, body and timing together. This project reconstructs that motion in 3D, learns a vocabulary for it, generates it from text, and then asks the hard question: how would you know if it were any good?

06/ 08Research2026

Beyond the heat map

A satellite can tell you where a city is hot. This study asks who lives there. Rank Phoenix’s neighborhoods by heat alone, then by heat plus vulnerability, and the two lists disagree at the top.

07/ 08Research2026

ZenithSync Assay Planner

Each well in a drug-response experiment costs the same, and there are never enough. This planner chooses the next few so that the response curve becomes as certain as possible.

A better test for an agent

Before asking whether a coding agent got better, ask what it was tested on. This is a workshop for that question: sealed test rooms, hidden tests, and four gates every training example must pass.
